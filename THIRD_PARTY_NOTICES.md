# Third-Party Notices

Mycorrhizal CRM distributes the following third-party software in its all-in-one
container image and, in builds that ship the on-device server, in the Go server
embedded in the Android app. Each entry records the package, its version, the
declared license, its source, and the license text that must accompany a
distribution. The Go standard library is included as one entry for the
toolchain pinned by backend/go.mod.

This file is generated by `cd backend && go run ./cmd/gennotices`. Do not edit it
by hand: change a dependency, then regenerate and commit the diff. The required
`Docs & security-doc citations` check in `.github/workflows/unit-tests.yml`
fails when the committed file is stale (issue #1944).

The Android APK/AAB embeds the IBM Plex fonts. Builds that ship the on-device
server also embed this Go server (including the Go standard library). This file
and THIRD_PARTY_SOURCES.md are packaged into the app and shown under
Settings > About > Third-party licenses; the Gradle dependency graph is
attributed separately by AboutLibraries. npm packages are web-only and are not
part of the APK/AAB.

Bundled content assets (fonts, icons) and their full license texts are in
THIRD_PARTY_SOURCES.md, shipped in the container at
/app/THIRD_PARTY_SOURCES.md and served at /third-party-sources.txt.

import { Bezier } from "bezier-js";
