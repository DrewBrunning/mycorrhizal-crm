# Migration test matrix

Use this after the skill's step 5. Pick the class that matches the change; the
test layer is the lowest one that can catch that failure (`docs/development/testing.md`).

| Change class | Up/down shape | Data-preservation proof | Floor / dump / release impact |
|---|---|---|---|
| Add nullable column | up adds, down drops | existing rows keep every prior field; omitted row reads its default | none unless a release ships the migration |
| Add required column with default | up adds with a constant/backfill, down drops | old rows get the documented default, not an empty value | dump for the next release |
| Rename column | up adds + copies + drops old, down reverses with a copy | copy equality and a rollback round-trip on a populated fixture | dump; call out the rename in upgrade notes |
| Retype / reinterpret | up/add + lossless conversion + drop, down reverses if lossless | values decode to the same meaning after `up → down → up` | dump; require an explicit decision if lossless is impossible |
| Drop column/entity | up drops, down recreates | only after a recorded decision; down proves the schema, not the lost rows | dump; call out in the release note |
| New index/constraint | up creates, down drops | the migration succeeds on populated rows; duplicate-key failures are explicit | dump if shipped |
| New entity | up creates, down drops | cascade registration test and delete semantics | dump; update `docs/security/pii-inventory.md` |
| Backfill-only | up rewrites rows, down is a no-op or reversal | before/after query count and values on a populated fixture | dump if the schema moves |

## Owning tests

- Migration shape, version, dirty flag: `backend/database/migrate_version_test.go`.
- Data preservation: `backend/database/migrate_datapreservation_test.go`.
- Interrupted startup and recovery: `backend/database/interrupted_startup_test.go`.
- Supported-release upgrade hops: `backend/internal/schemafixture/` and
  `backend/internal/schemafixture/upgrade_test.go`.
- Frozen dumps: `backend/database/testdata/schemas/`, generated by
  `backend/cmd/genschema`.

## Release impact

A release without a dump for its tag fails `schemafixture-suite` and the
docker-publish schema-fixture gate. The floor is `v1.0.0`; do not add a release
below it to `backend/internal/schemafixture/releases.go`.

Canonical: `docs/upgrade-compatibility.md`, `backend/database/AGENTS.md`.
